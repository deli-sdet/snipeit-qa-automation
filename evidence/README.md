# Execution evidence

Generated by running the suite; commit the results of the runs you submit.

| Artifact                                              | Produced by                                          | Copy here as                             |
| ----------------------------------------------------- | ---------------------------------------------------- | ---------------------------------------- |
| HTML report (traces, screenshots, videos of failures) | `npm test` → `playwright-report/`                    | `evidence/playwright-report/` (or a zip) |
| JUnit XML                                             | CI → `results/junit-*.xml`                           | `evidence/junit/`                        |
| Console summary                                       | `npm test 2>&1 \| tee evidence/run-<date>.log`       | `evidence/run-<date>.log`                |
| Postman/Newman results                                | `npm run test:postman` → `results/postman-junit.xml` | `evidence/postman-junit.xml`             |
| Screenshots of key steps                              | trace viewer / manual                                | `evidence/screenshots/`                  |

Record environment, date, app version (footer of the demo), pass/fail/flaky/skipped counts and any locator adjustments in [`RUN-NOTES.md`](RUN-NOTES.md).
